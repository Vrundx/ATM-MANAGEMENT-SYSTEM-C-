# 🏧 ATM Management System (C++)

A simple console-based ATM Management System built using C++. This project simulates the basic functionalities of an ATM and is designed to strengthen fundamental C++ programming concepts.

## Features
- 🔐 PIN Authentication
- 💰 Check Account Balance
- 💵 Deposit Money
- 💸 Withdraw Money
- 📋 Menu-driven Interface
- 🚪 Exit Option

## Technologies Used
- C++
- Visual Studio Code
- Git & GitHub

## Concepts Used
- Functions
- Switch Statement
- Loops
- Conditional Statements
- Variables
- User Input/Output

## How to Run

Compile:
```bash
g++ ATMManagementSystem.cpp -o atm
